TorchEEG distributes independent interfaces, validation and physical metadata
handling, and a new mean-token classification head. It distributes neither
author implementation code nor pretrained weights. The library interface
does not import or download source. The caller explicitly supplies a trusted
complete nn.Module backend. The standalone example imports local author
source explicitly, separately from restricted tensor-only checkpoint loading.
The optional native CI obtains pinned source and verifies the separate weight
hash. These materials are not added to wheels or source distributions.
