TorchEEG distributes independent interfaces, validation, physical metadata
handling and a new task classification head. It does not distribute author
implementation code or pretrained weights. Library imports neither import
nor download author source. The caller supplies an explicitly constructed
trusted complete nn.Module backend. Standalone examples explicitly import
separately obtained local source; that action is separate from restricted
tensor-only checkpoint loading. The optional native CI obtains the pinned
source, verifies its license and validates the complete weight SHA256.
No author source or weights are included in wheels or source distributions.

The author source identifies code derived from learning-from-brains and
EEG-Conformer/Braindecode, including original BSD-3 notices in encoder files.
Retain the original source tree and its notices when obtaining that backend.
