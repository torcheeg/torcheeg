TorchEEG's MIT license does not replace the original authors' permissions.

TorchEEG distributes independent interfaces, metadata handling and new-task
classification code. It does not distribute author model implementation code,
official weights, or the separately supplied disease-label mapping.
Its library interfaces neither import nor download author source.
The caller explicitly constructs a trusted local nn.Module backend.
Standalone examples explicitly load separately obtained local author source;
that action is separate from restricted tensor-only checkpoint loading.
The optional external CI job obtains the fixed checkout and validates
checkpoint hashes, retaining the original source/model license in that tree.
The author demonstration data are expressly synthetic; numerical examples
must not be presented as clinical validation or calibrated risk estimation.
