The temporal convolution, query/key normalization, asymmetric query/value
bias option, layer scales, channel/temporal embeddings, transformer blocks
and tensor names follow modeling_finetune.py and modeling_pretrain.py.
Upstream credits BEiT-v2, timm, DeiT and DINO:
https://github.com/microsoft/unilm/tree/master/beitv2
https://github.com/rwightman/pytorch-image-models/tree/master/timm
https://github.com/facebookresearch/deit/
https://github.com/facebookresearch/dino

The channel catalog follows utils.py. Its 136 entries exceed the checkpoint's
128 electrode slots; names without a native embedding slot are rejected.
TorchEEG exposes raw and normalized tokens, strict shape/channel checks,
explicit temporal-table interpolation and complete safe encoder loading.
The native learned norm remains named norm. It is not silently renamed to
a newly initialized downstream fc_norm. Native convolution and attention
operation ordering is retained for numerical reproducibility.

Neural spectrum tokenizer, masked-code prediction, contrastive projection,
optimizer and trained downstream heads are not restored by encoder loading.
No author checkpoint is redistributed. Independent fixtures use deterministic
synthetic tensors and unmodified author computation, with timm0.4.12 only
in the separate reference environment. TorchEEG has no timm dependency here.


Downstream wrappers retain the archived TorchEEG workspace's channel-major
flattening and two-hidden-layer ELU task topology. They expose complete
native encoder norm restoration, configurable hidden widths/dropout,
explicit window/independent-patch Fourier resampling and freeze/eval control.
Task heads start from fresh weights; encoder loading does not restore any
trained task head. Resampling input/parameter gradients are checked against
an independent dense SciPy operator and unmodified native encoder reference.


Registered adapter blocks retain the archived TorchEEG workspace's two
post-residual bottleneck positions, preserving native layer-scale parameter
objects and state paths. The shared EEGPT bottleneck implementation is reused
with zero-initialized up-projections for deterministic identity at insertion.
The archived nonzero-adapter/native-block computation supplies an independent
synthetic output/gradient fixture; no pretrained adapter weights are claimed.


Registered attention prefixes preserve the archived workspace's learned
key/value layout and insertion after native key normalization. Module-owned
parameters replace forward closures and support full state restoration.
Independent synthetic fixtures use the unmodified archived prefix helpers
and official native encoder; no pretrained prefix weights are supplied.


Registered low-rank projections reuse the existing EEGPT linear adaptation
implementation. Exact block-relative targets replace substring matching;
input dropout is module-owned, and both ordinary/prefix attention evaluate
QKV through the module so its update is effective. Independent fixtures use
unmodified author encoder computation with a separate weight parametrization
and archived LoRALayer at dropout zero. No pretrained LoRA weights are supplied.
