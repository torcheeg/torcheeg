TorchEEG documentation
======================

TorchEEG is a Python library for EEG analysis with PyTorch. It connects
datasets, signal and label transforms, evaluation partitions, neural networks,
and trainers in one workflow.

Start here
----------

* :doc:`installation`: install the library and optional components.
* :doc:`user_guide/index`: understand the data and training workflow.
* :doc:`reference/index`: find classes, functions, parameters, and input shapes.
* :doc:`tutorials/index`: follow the library components in order.

Select examples that match your dataset, signal format, and evaluation
protocol. A subject-based experiment needs different partitions from a
within-subject experiment. State preprocessing and label mappings when
reporting a result.
