# ShallowConvNet numerical references

The JSON fixtures are independent reference results. Running TorchEEG tests
does not require Braindecode or the EEG-Arena repository.

`shallow_convnet_reference.json` was generated with Braindecode 0.8.1's
`ShallowFBCSPNet`, `final_conv_length='auto'`, mean pooling, evaluation mode,
float64, and `add_log_softmax=False`. The official PyPI wheel SHA256 is
`6c2a571095a6ca366ade93a1a12bafce3225ce7d395eca6f7e2eb66edb5dd7da`.
The fixture records the installed source file's SHA256 and runtime version.
The retained BSD license is in `LICENSES/Braindecode.txt`.

`shallow_convnet_arena_reference.json` was generated by executing the unchanged
EEG-Arena ShallowConvNet backbone, wrapper, and shared layers at commit
`c1aa1292aed21c0e170dd0da3cd0a4a60581f6ad`. File hashes are recorded in the
fixture. This repository's source is not redistributed here. The numeric
cases exercise the actual no-temporal-bias, convolution max-norm 2.0 and
classifier max-norm 0.5 configuration. They do not assert that TorchEEG uses
the same random initialization sequence or preprocessing benchmark protocol.
TorchEEG calculates the classifier dimensions without a dummy training
forward, so construction leaves batch normalization statistics clean.

All cases use two synthetic windows with values
`sin(arange / 17) + cos(arange / 31)`. They contain no EEG dataset samples.
Weights use the `canonical_linspace_v1` specification in
`test/models/test_shallow_convnet.py`. The constrained reference multiplies
convolution/classifier weights by 80 before forward to trigger projection.
Braindecode temporal/spatial/classifier kernels are transposed between its
time-first internal layout and TorchEEG's electrode-first layout. EEG-Arena's
linear classifier weights are reshaped into the full-window convolution.

Each fixture stores logits and gradient summaries for mean squared logits:
the first eight entries, sum, and L2 norm of the input gradient and every
parameter gradient. Functional tests compare those independent values and
also check optimization, zero windows, state restoration, constraint bounds,
parameter ownership, accumulated backward, and frozen inference behavior.

## DeepConvNet references

`deep_convnet_reference.json` uses the same verified Braindecode 0.8.1 wheel
and records the `Deep4Net` source hash. Three classic configurations use
batch normalization, ELU, max pooling, a shared temporal kernel and automatic
final convolution size. `deep_convnet_arena_reference.json` records three
independent pinned EEG-Arena cases, including a 128-sample input that adapts
the shared kernel from ten to two samples. The numeric state/input algorithms
and gradient summaries follow the ShallowConvNet specification above, with
normalization settings applied to all four blocks.

The source Deep4Net version has a constructor bug in its optional no-BatchNorm
branch. That branch is not patched or represented as independently verified
here; TorchEEG tests its own no-BatchNorm shape, optimization and gradient
behavior separately. DeepConvNet starts in training mode for consistency
with other TorchEEG modules; numerical reference comparisons use explicit
evaluation mode. Both source implementations are used only as numerical
oracles, without importing them during the shipped tests.

DeepConvNet reference generators use two CPU threads. Reference comparisons
set the same thread count and restore the previous count after each case
group. Parallel reductions can change gradient sums for the deliberately
oversized constrained state; production modules do not change thread settings.

## EEGPT encoder references

`eegpt_reference.json` uses the unmodified official encoder from
BINE022/EEGPT at ea7282f698c406cd423ccbedbe9960853761144c,
`downstream/Modules/models/EEGPT_mcae_finetune.py`. Its SHA256 is stored in
the fixture. Apache-2.0 license and adaptation provenance are retained in
LICENSES/EEGPT.txt and LICENSES/EEGPT-NOTICE.txt. No checkpoint is included.
Four float64 cases use two CPU threads, deterministic linspace weights,
and sin/arange + cos/arange windows. They cover ordinary and overlapping
patches, flattened patch/electrode selection, and temporal selection.
The loss is mean squared (output * sin(arange / 13)); outputs, first eight
entries, sum and L2 norm of every input/parameter gradient are recorded.
Comparisons restore the caller's thread count after reference evaluation.

The official mask_t branch reshapes with the pre-selection patch count.
For this case the reference script selects the requested time positions
from the official full output, without editing upstream code. It defines
the intended result independently; it does not claim the broken branch ran.
Normalized-patch projection is an original-workspace option, tested against
unfold/normalization/linear arithmetic and optimization separately.
No fixture result establishes pretrained performance or task accuracy.


## CBraMod task heads

`cbramod_head_reference.json` was generated independently from the unmodified
MIT `models/model_for_bciciv2a.py` at b9e961003214326972c567eff390e75b0287e32a.
The file's SHA256 is recorded in the fixture and asserted before generation.
Its four native head modules were evaluated in float64 on deterministic
[1, 22, 4, 200] features. Only the backbone was replaced with Identity to
isolate the task heads; no head computation was changed. Native backbone
numerics are independently covered by `cbramod_reference.json`.

For linear-layer index i, weights are
`((row * 7 + column * 3 + i) % 19 - 9) / (19 * sqrt(in_features))`, and
biases are `(row % 7 - 3) / 20`. Input features are
`(arange(17600).reshape(1,22,4,200) % 71 - 35) / 35`.
The scalar objective is the dot product of output and [0.2, -0.3, 0.7].
Fixture output, selected feature gradients and per-linear-layer weight-gradient
sum/norm/first entries and complete bias gradients are checked. Pooling,
flattening order, nonlinearities and all four head topologies are covered.
No upstream checkpoint or patient signal is stored in the fixture.

## BIOT

`biot_reference.json` was generated from unmodified official `model/biot.py`
at d138e32634e52ae9fa6ec98ac9c4087b14ca869a with the PyPI
linear-attention-transformer 0.19.1 noncausal global attention implementation.
Both source SHA256 values are in the fixture. PyTorch 2.6 CPU, float64, two
threads. Canonical width256/heads8/depth4/18 channels, two input channels,
400 samples; deterministic `reference_state` from test_eegpt except native
index/position buffers. Input is sin(arange/17)+cos(arange/31), seed913 before
forward; loss is mean((output*sin(arange/13))**2). The first three position
rows are copied verbatim from the author model into the fixture, so platform
trigonometric rounding does not change the reference input. Cases cover eval,
training with controlled dropout, zero EEG, and native channel offset2.
For training, both reference and test use mask arange(numel)%10 >= p*10
and division by 1-p, checking placement/scaling independently of version-specific
RNG kernels. A separate test checks actual random dropout reproducibility,
training variation, and deterministic evaluation on each supported runtime. Store all outputs
and first8/sum/norm summaries for input and every trainable parameter gradient.
No upstream package, network or pretrained weights are needed by CI. This
fixture is an architecture regression test, not a pretrained accuracy claim.
The three actual official checkpoints were separately loaded and compared
against the reference, including every parameter gradient; see the BIOT guide.

## BENDR

`bendr_reference.json` uses unchanged DN3 layers.py classes at revision
4d477fe42d3d8ce64f3b790585bfa5c7acb84848 (full source hash in fixture).
Extracted class definitions avoid unrelated legacy package imports; their
bodies are unchanged. PyTorch2.6 CPU/float64/two threads, encoder3->16,
context width16/mlp32/heads4/depth2, encoder dropout.1/context.15,
input2x3x385 sin(arange/17)+cos(arange/31), reference_state per native
component key. Loss mean((output*sin(arange/13))**2). Eval/train/zero/explicit
time+channel masks; save all outputs and input/every parameter gradient
summaries, including None for native unused parameters. Training dropout
uses controlled scalar/channel masks arange%10>=p*10 divided by1-p for
version-independent placement/scaling checks. Attention-probability dropout
is set to zero in the training reference because fused SDPA RNG differs
between supported Torch versions; its native probability.15 and stochastic
behavior are separately tested. Full 512-wide/eight-layer actual released encoder24 and
context76 tensors are compared independently against DN3, not represented
as pretrained by these small synthetic fixtures. BSD notice LICENSES/BENDR.txt.
